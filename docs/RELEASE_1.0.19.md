# v1.0.19 勤務時間を数字4桁で入力

勤怠時間修正の出勤・退勤時刻は、コロンを打たずに数字4桁で入力できます。

- `0901` → `09:01`（午前9時1分）
- `1810` → `18:10`（午後6時10分）
- `2507` → `25:07`（翌日午前1時7分）

入力欄を離れると自動で整形します。欄に移動すると現在の時刻が全選択され、そのまま数字4桁で置き換えられます。
従来の `HH:mm` 入力と保存値は引き続き利用できます。時刻は24時間表記で、対応範囲は `00:00`〜`47:59` です。不完全な入力や `0960` などの不正な時刻は送信できません。
休憩欄、修正理由の必須条件、申請経路は変更していません。

## 更新方法

既存アプリを一度終了して起動し、画面上部に「v1.0.19 の準備完了」が出たら「再起動して更新」を押してください。
手動でインストーラーをダウンロードする必要はありません。

## 検証

2026年10月19日、ブラウザーテストで4桁の連続入力、欄を離れたときの整形、フォーカス中の4桁から正しい送信形式への変換、保存復元、不正値の拒否、日またぎ、休憩の追加削除を確認しました。APIは模擬し、外部通信を遮断しています。
型検査・本番ビルドと、配布用v1.0.19実アプリでの4桁の連続入力、自動整形、日またぎ、不正値の拒否、休憩初期値の維持を確認しました。実画面の画像も確認済みです。実アプリの検証には空の専用設定を用い、実設定や自動承認タスクから隔離しています。
公開後、導入済みの旧版v1.0.18から、認証なしでv1.0.19を検出・ダウンロードし、配布物とのSHA256一致と「再起動して更新」ボタン表示を確認しました。空の設定・専用キャッシュで検証し、実設定のハッシュ不変も確認しています。公開直後の初回検証は60秒のタイムアウトになり、アプリを再起動した再検証で成功しました。初回の原因は特定していません。
実freeeへの申請送信、更新適用後の設定保持、他PC固有のネットワーク・セキュリティ制限は未検証です。
