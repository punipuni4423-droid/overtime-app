# v1.0.18 更新内容

勤怠時間修正の出勤・退勤時刻を、リストを開かずに1分単位で手入力できます。
`09:07`、`18:43` のように入力してください。翌日分は `25:07` の形式で、`00:00`〜`47:59` を指定できます。

この機能は2026年10月1日のソース更新で実装済みでした。今回の配布版に含めます。
休憩時間の入力、追加・削除、修正理由必須、申請経路の扱いは現在の実装を維持します。
同じソース更新に含まれる申請の取り下げ・削除の状態確認改善も含みます。

## 検証範囲

2026年10月19日：型検査と本番ビルド、取り下げ・削除の回帰テスト17件、勤務時刻入力と取り下げ画面のブラウザーテストを実施して成功。
ブラウザーテストでは1分単位の入力・送信データ形式、入力値の保存復元、不正値の拒否、日またぎ、休憩の追加削除を確認しました。APIは模擬し、外部送信を遮断しています。

配布用アプリの検証も `node scripts/check-packaged-minute-input.mjs` で実施して成功しました。
空の設定でv1.0.18の実アプリを起動し、既存の設定と自動承認タスクを保護して、送信せずに1分単位の手入力、日またぎ、不正時刻のエラー、休憩初期値を確認しました。実画面の画像も確認済みです。
実freeeへの申請送信と、更新適用後の設定保持は、この検証では確認していません。

## 既存アプリ内からの更新

2026年10月19日、利用者の明示承認に基づき、更新元の `punipuni4423-droid/overtime-app` を一般公開に変更しました。ソースコード・部署名・マニュアルも公開対象です。セットアップEXE、対応するblockmap、自動更新用 `latest.yml` の内容は変更していません。

既存アプリを一度終了して起動し、画面上部に「v1.0.18 の準備完了」が出たら「再起動して更新」を押してください。手動でインストーラーをダウンロードする必要はありません。

`node scripts/check-installed-update.mjs` で、このPCに導入済みの旧版v1.0.17から、認証なしでのv1.0.18検出、実ダウンロード、SHA256一致、「再起動して更新」ボタン表示を確認しました。検証は専用の空設定・更新キャッシュで行い、実設定のハッシュ不変を確認しています。既存自動承認タスクへのアクセスを遮断し、終了時の自動インストールを防いで検証プロセスを終了しました。

更新ボタンの押下と実インストール、他PC固有のネットワーク・セキュリティ制限、更新適用後の設定保持は未検証です。
